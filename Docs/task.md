# 验收规格

目标是在《影之刃零》中正常操作《异环》零，交付模型、原生骨架绑定、动画、材质、武器交互、安装工具以及可复现工程。

| 项目 | 通过条件 |
|---|---|
| 外观 | 脸、银发、服装、贴图与人物比例正确 |
| 待机 | 呼吸与细微动作连续 |
| 移动 | 行走、奔跑、台阶、跳跃变形自然，脚步贴地 |
| 战斗 | 普攻连招、受击、闪避的肢体连续 |
| 颈部 | 正面、侧面及转头俯仰的长度和变形自然 |
| 手指 | 指尖、握柄、张手和握拳形态自然 |
| 武器 | 握持、拔收刀与刀鞘跟随正确 |
| 稳定性 | 连续游玩十分钟，覆盖传送、过场和场景切换 |
| 安装 | PBZModKit 安装生效、卸载恢复 |

用户提供实机截图或录屏，并对应本次运行日志。离线资产检查、cook 和反解报告作为进入实机验收的前置门槛。
